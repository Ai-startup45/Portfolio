# Priyanshu Chatterjee · Portfolio

Personal portfolio for Priyanshu Chatterjee, video editor and motion designer (Delhi).
Live at **https://priyanshuchatterjee.vercel.app**

## How to change text, links or projects (no coding needed)
1. On GitHub, open `js/content.js` and click the pencil icon (Edit).
2. Change the words between the quotes `" "`. Don't delete quotes or commas.
3. Click **Commit changes**. Vercel republishes the site in about a minute.

## How to add a new project
Copy one project block in `js/content.js` (from `{` to `},`), paste it below, and change the text and YouTube link.
For the preview video and thumbnail, upload a short muted MP4 (under 1 MB) to `assets/video/` and a JPG to `assets/img/` (GitHub: **Add file → Upload files**), then put their names in the block.

## What's inside
- `index.html` page structure, title and share-preview tags
- `css/style.css` colours, fonts, layout ("Edit Suite" palette: `#0B0B0C`, `#F2F0EB`, accent `#FF4D2E`)
- `js/main.js` loader, letter wave, tilt, video previews, 3D film strip (no libraries)
- `assets/` showreel, previews, images, Anton font

The showreel music is an original composition made for this site, so it is free to use.
